# AMANA data

## `processed/amana_bench.jsonl`: AMANA-Bench (synthetic, controlled)

English medication instructions with Arabic translations. Each row pairs one instruction with one
clinically critical error.

| field | meaning |
|---|---|
| `src_en` | English instruction, as a prescriber or pharmacist would write it |
| `ref_ar` | correct Arabic translation (reference style) |
| `good_ar` | correct Arabic translation in a different style (synonyms, digits, word order, spelling) |
| `bad_ar` | reference with one critical error (minimal edit) |
| `bad_matched_ar` | `good_ar` with the same critical error (same surface style as `good_ar`) |
| `error_type` | one of 11 types: dose, strength, unit, frequency, duration, timing, route, laterality, negation, omission, drug |
| `error` | what changed, e.g. `strength 20 -> 200 mg`, `drug hydralazine -> hydroxyzine (LASA)` |
| `split` | train / dev / test, **split by drug**: test drugs never appear in training |
| `slots` | the structured clinical content behind the instruction |

Generated by `scripts/01_build_bench.py` (seed 13): 3,180 instructions, 56 drugs, 8 dosage forms,
25,258 contrastive rows. The Arabic follows the number-agreement rules of Modern Standard Arabic
(dual, 3-10 plural, singular accusative for 11+). Drug-name pairs that look or sound alike follow
the ISMP list of confused drug names.

Labels are exact by construction, because errors are injected into the structure and not into the
text. Regimens are kept clinically plausible (for example, methotrexate is always weekly and
statins once daily), but they are **not** prescribing advice.

## `processed/amana_tico.jsonl`: AMANA-TICO (real text)

Built from the professional English→Arabic translations of the
[TICO-19](https://tico-19.github.io/) test set (CC0). One number is changed, or one negation
particle (لا / لم / لن) is removed, in the human reference. Benign variants are orthographic only.
Generated by `scripts/02_build_tico.py`, which downloads the test file if it is missing.

The 703 rows come from Wikipedia, PubMed, Wikinews and Wikisource sentences. None come from the 104
CMU doctor-patient sentences in the test file: they have no digits and no English negation, so neither
injector applies. The rows are general COVID-19 and medical prose, not medication instructions. This is real
text with controlled errors, not a test on natural errors.

## `hard_cases_holdout.jsonl`: linguistic hold-out

20 clinical errors and 20 safe paraphrases, written by hand and frozen by SHA-256 (recorded in
`scripts/10_guard2_eval.py`) before AMANA-Guard 2 was implemented. Same author as the checker, not blind, and
now spent. Do not edit it or tune on it.
